# SaaS API and SCIM examples

Historical Postman collections demonstrating SaaS administration, user provisioning, and account updates. Some requests are unfinished examples; review methods, target tenants, user IDs, and request bodies before sending them.

Authentication uses named `{{UPPERCASE_VARIABLES}}` supplied by a private Postman environment. Do not save real credentials into these collection files. See [configuration instructions](../docs/configuration.md#postman-collections) for private rendering from local environment variables or GitHub Actions secrets.
